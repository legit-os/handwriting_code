# Language smoke-test files

Open one of these files in NoteBookIDE and press **Run**. Each file runs a tiny assertion and prints a pass message. Checking syntax with **Ctrl+K** also exercises the matching local checker/compiler. The matching runtime or compiler must be installed and available on `PATH`.

| File | Runtime / compiler |
| --- | --- |
| `python_test.py` | Python |
| `javascript_test.js` | Node.js |
| `typescript_test.ts` | TypeScript compiler and Node.js |
| `Main.java` | Java JDK |
| `c_test.c` | GCC |
| `cpp_test.cpp` | G++ |
| `go_test.go` | Go |
| `rust_test.rs` | Rust |
